# Changelog

## [2.0.0] - Pending release

### Changed
- Rebranded the application as **Labelizer4x6**.
- Replaced the original interface with a modern dark-purple PySide6 UI.
- Added a PDF queue, drag-and-drop loading, and per-file removal.
- Added automatic shipping-label detection in addition to manual crosshair cropping.
- Added a live 4 × 6 preview, Undo Crop, sizing options, and label rotation.
- Added direct Windows printing and optional opening of the saved PDF.
- Saved labels are named using the original document name followed by a timestamp.
- Added 4 × 6 PDF output and artwork.

### Notes
- Intended for Windows 10/11. A 4 × 6-compatible printer driver is required for direct printing.
- Always review shipping barcodes and verify print scaling.

## [1.0.0] - 2024-11-19

- Original EasyLabel Extractor release, with manual PDF region selection and PDF export.
