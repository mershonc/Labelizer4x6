# Labelizer4x6 v2.0.0

Labelizer4x6 is the second major release of Carson's EasyLabel Extractor. It extracts shipping labels from return PDFs and prepares 4 × 6 PDFs for thermal label printers.

## Highlights

- Modern purple desktop interface
- Automatic shipping-label detection and manual crosshair cropping
- Drag-and-drop support for multiple PDF files
- Live 4 × 6 label preview, rotation, and Undo Crop
- Sizing modes: Stretch selection, Fill page, Fit entire selection
- Direct printing through the Windows print dialog
- Save as `OriginalName_YYYY-MM-DD_HH-MM-SS_4x6.pdf`
- Optional opening in the default PDF application

## Download

The standalone Windows `Labelizer4x6.exe` will be attached to the **v2.0.0** GitHub Release after the source update is merged and the build has been tested.

## Printing

Select 4 × 6 inch label stock in your printer settings, and verify the barcode orientation and print size before printing your first label.
